Requisito para usar OasisBot

.NET 8 Desktop Runtime (x86): la versión de 32 bits, aunque tu Windows sea de 64.

I

Por qué hace falta

OasisBot es un programa de 32 bits (x86) y necesita el .NET 8 Desktop Runtime de 32 bits.

Aunque tu Windows sea de 64 bits, tienes que instalar la versión x86.

  • Casi todas las PC son de 64 bits, pero OasisBot necesita igual el runtime de 32 bits.
  • El runtime de 64 bits (x64) NO sirve y no reemplaza al de 32 bits.
  • Instalar el de 32 bits en una PC de 64 bits es normal, no da problemas y puede convivir con el de 64.

Si no está instalado, el bot no abre y no muestra ningún error.

II

Cómo verificar si ya lo tienes

  1. Abre PowerShell: Inicio, escribe PowerShell y presiona Enter.
  2. Pega todo este bloque junto y presiona Enter. Funciona en Windows de 64 y de 32 bits: 
    $d = if ([Environment]::Is64BitOperatingSystem) { "${env:ProgramFiles(x86)}\dotnet\shared\Microsoft.WindowsDesktop.App" } else { "$env:ProgramFiles\dotnet\shared\Microsoft.WindowsDesktop.App" }
$v = Get-ChildItem $d -Directory -ErrorAction SilentlyContinue | Where-Object { $_.Name -like "8.*" }
if ($v) { "OK: ya tenes .NET 8 Desktop Runtime x86 (version " + $v[-1].Name + ")" } else { "FALTA: instalar .NET 8 Desktop Runtime x86" }
  3. Lee la respuesta.
  • Responde “OK: …”: ya lo tienes, no hay que instalar nada.
  • Responde “FALTA: …”: sigue con el paso III.

No uses dotnet --list-runtimes para comprobarlo: en una PC de 64 bits solo muestra el runtime de 64 bits y puede decir que falta cuando en realidad sí está instalado.

III

Cómo instalarlo (opción recomendada, con winget)

  1. En PowerShell, pega este comando exacto y presiona Enter: 
    winget install Microsoft.DotNet.DesktopRuntime.8 --architecture x86
  2. Acepta los términos si los pide y espera a que diga “Instalado correctamente”.
  3. Vuelve a ejecutar el bloque del paso II para confirmar que ahora dice “OK”.
IV

Si winget no funciona o no existe (alternativa manual)

Esta opción sirve para todos.

  1. Entra a este enlace oficial de Microsoft, que descarga directo el instalador de 32 bits (x86): aka.ms/dotnet/8.0/windowsdesktop-runtime-win-x86.exe
  2. Ejecuta el archivo descargado (pesa unos 51 MB), acepta y espera a que termine.
  3. Verifica con el bloque del paso II.

Si instalas por error el instalador “x64”, no sirve: tienes que instalar el “x86”.

V

Si después de instalarlo el bot sigue sin abrir

Puede ser el antivirus de Windows (Defender o “Control inteligente de aplicaciones”) bloqueándolo. En ese caso, avisa al soporte del server.
